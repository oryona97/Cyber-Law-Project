# Project Implementation Summary

## Overview
This project is a full-stack "CyberLaw" assistance platform designed to triage user legal inquiries via a WhatsApp chatbot (or web interface), generate leads for lawyers, and provide a management dashboard for administrators and secretaries.

## 1. Architecture & Infrastructure
The system uses a containerized microservices architecture managed by **Docker Compose**.

*   **Backend:** Node.js (v20+) with Express.js.
*   **Frontend:** React (Vite).
*   **Database:** PostgreSQL (v15).
*   **AI Engine:** Ollama (running local models like `llama3`).
*   **Automation:** `n8n` has been **REMOVED** as it was deemed unnecessary for the current workflow.

## 2. Backend Implementation (`/backend`)

### A. Core Logic & Controllers
*   **WhatsApp Controller (`whatsappController.js`):**
    *   **Stateful Chatbot:** Manages user sessions (`Conversation` model).
    *   **Topic Selection:**
        *   New users are presented with a numbered menu of active topics (e.g., "1. CyberLaw", "2. Family Law").
        *   Validates user input and assigns a `topic_id` to the conversation.
    *   **AI Integration:** Forwards user messages to the AI service, injecting the specific System Prompt associated with the selected topic.
    *   **Automated Triage & Lead Generation:**
        *   Monitors conversation depth (`Message.count`).
        *   Triggers automatically when `max_depth` (from `ExpertConfig`) is reached.
        *   **AI Summarization:** Calls a specialized AI prompt to generate a JSON summary (Issue + Urgency).
        *   **Lead Creation:** Saves the summary to the `Lead` table.
        *   **Contact Capture:** Switches conversation status to `waiting_for_lead` and captures the user's next message as contact details for the lead.

*   **AI Service (`aiService.js`):**
    *   `generateResponse(prompt, systemPrompt)`: Generates standard conversational replies using the Ollama API.
    *   `generateLeadSummary(history)`: A specialized function that forces the AI to output a structured JSON object (`{ summary, urgency }`) for lead creation, used during triage.

*   **Admin Controller (`adminController.js`):**
    *   Provides API endpoints for managing topics and their associated expert configurations.
    *   `GET /api/admin/topics`: Fetches all topics with their `ExpertConfig`.
    *   `PUT /api/admin/topics/:id`: Updates topic details (name, description, active status).
    *   `PUT /api/admin/experts/:id`: Updates an `ExpertConfig`'s system prompt and `max_depth`.

*   **Secretary Controller (`secretaryController.js`):**
    *   Provides API endpoints for managing leads and lawyers.
    *   `GET /api/secretary/leads`: Fetches all generated leads, including associated user, topic, and assigned lawyer information.
    *   `GET /api/secretary/lawyers`: Fetches all active lawyers.
    *   `POST /api/secretary/leads/:id/assign`: Assigns a lawyer to a specific lead and updates its status.

### B. Database Schema (Sequelize ORM)
*   **User:** Stores WhatsApp number and name.
*   **Topic:** Categories of law (Cyber, Family, IP) with descriptions.
*   **ExpertConfig:** Stores the AI "Persona" (System Prompt) and `max_depth` settings for each topic.
*   **Conversation:** Tracks the active topic and status (`active`, `waiting_for_lead`, `closed`).
*   **Message:** Stores the full chat history (User vs. AI).
*   **Lead:** Stores the AI-generated summary, urgency, and links to the user/conversation, topic, and assigned lawyer.
*   **Lawyer:** Stores lawyer details (name, email).

### C. Initialization
*   **Seeding (`seed.js`):** Automatically populates the database with initial topics and expert configurations (e.g., "CyberLaw", "Family Law").

## 3. Frontend Implementation (`/frontend`)
The frontend is a **Vite + React** application, fully implemented and redesigned for a professional and modern user experience.

*   **Global Styling:** Custom CSS (`index.css`) for a consistent dark/professional color palette, modern typography, card-based layouts, and responsive design. Uses `bootstrap` and `bootstrap-icons`.
*   **Navigation:** A responsive `Navbar` provides easy access to different sections.
*   **Routing:** `react-router-dom` handles navigation between pages.
*   **Home Page (`/`)**: A welcoming landing page with quick links to the main dashboards.
*   **Admin Page (`/admin`)**:
    *   Displays a structured table of all legal topics and their associated AI expert configurations.
    *   Includes a preview of the AI system prompt and `max_depth`.
    *   "Edit" buttons for future topic/expert configuration management.
*   **Secretary Page (`/secretary`)**:
    *   Presents leads in a card-based dashboard layout.
    *   Highlights lead urgency and topic.
    *   Allows secretaries to assign available lawyers to leads via a dropdown menu (currently without email notification).
*   **Test Interface (`/test`)**:
    *   A "WhatsApp Simulator" chat interface for testing the backend's chatbot logic.
    *   Simulates sending messages to the webhook. (Note: AI replies are logged in backend console as the simulator does not yet fetch them real-time).

## 4. Current Workflow (Tested)
1.  **User says "Hi" (via WhatsApp or Simulator)** -> Bot replies with a numbered Topic Menu.
2.  **User picks Topic (e.g., "1" for CyberLaw)** -> Bot confirms selection and associates the topic's AI persona.
3.  **Chat Continues** -> AI answers questions using topic-specific knowledge.
4.  **Triage Triggered** -> When conversation message count reaches `max_depth` (configured per topic, e.g., 10 messages), the AI generates a JSON Summary, creates a `Lead` entry in the database, and asks the user for contact information.
5.  **User sends Contact Info** -> System saves the provided information to the `User` record and marks the conversation as `closed`.
6.  **Admin/Secretary View** -> The newly created lead (with AI summary) is visible in the Secretary Dashboard.

## 5. Development Tools
*   **`simulate_chat.sh`**: A shell script using `curl` to automate a full conversation flow, from initial greeting to lead generation, for testing purposes.
